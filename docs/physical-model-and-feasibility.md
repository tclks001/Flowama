# 流沙麻将的物理模型与实现可行性

本文是 Flowama 的理论基线，用于回答“真实流沙麻将由哪些现象组成、哪些现象值得模拟、应采用什么近似、项目是否可行”。它不是已经完成的实现说明；文中的模型只有经过对应实验后，才能成为运行时契约。

结论中的证据分为三类：

- **观察**：可直接从本地参考视频辨认。
- **文献**：有论文、技术资料或专利支持的一般规律。
- **推断**：依据观察和文献作出的项目判断，仍需用实现或实物测量验证。

## 结论

项目在 PC 上具有开发可行性，但不适合将所有固体都建模成粒子，也不应使用一种算法包办全部现象。推荐的核心是一个混合的 2.5D 模型：

- 流沙油：薄腔中的二维深度平均不可压缩流体，保留惯性、平面黏性和薄腔阻尼。
- 珠光粉：按颜色、等效粒径和密度划分为少量连续浓度场，并具有各自的沉降速度。
- 可辨认的闪粉、亮片：使用显式拉格朗日粒子，数量可以达到约十万。
- 堆积层：通过最大固相体积分数、受阻沉降和沉积状态描述，不能只让浓度无限叠加。
- 光学：珠光的连续光泽和微小闪点、较大亮片的离散 glint、亚克力与油层分别渲染。

这条路线避免了对数十亿乃至更多微粒逐个积分，同时仍能表现分层、云雾、指状下沉、漂移、堆积和闪烁。它也适合用 OpenGL 计算着色器实现，能够服务本项目的 GPU 学习目标。

首个目标不应是严格复现某一种真实配方，而应是用少量可测参数复现参考视频的时空特征。未知材料参数通过视频标定，而不是靠增加求解器复杂度弥补。

## 实物与参考视频

### 已知的实物组成

流沙类亚克力摆件通常是密闭薄腔、透明流沙油和多种装饰固体的组合。一个相关的装饰流沙专利给出的实例使用运动黏度 32–35 mm²/s 的流沙油，并将亮片分为 0.1–0.5 mm、0.5–1.5 mm、1.5–3 mm 三档；这只能作为现实量级的参考，不能反推本地视频采用了相同配方。[CN111301048B](https://patents.google.com/patent/CN111301048B/zh)

珠光粉与普通塑料闪粉不是同一种视觉材料。常见云母基珠光颜料是涂覆二氧化钛和/或氧化铁的薄片，其颜色来自部分透射、反射和薄层干涉。FAO/JECFA 汇总的商用品种包含 1–15 μm、5–25 μm、10–60 μm 和 10–150 μm 等粒径范围。[FAO/JECFA 技术评估](https://www.fao.org/fileadmin/user_upload/agns/pdf/CTA_PAS_BPP_77.pdf)

因此，项目至少面对三个不同尺度：

| 表观尺度 | 实物角色 | 合适的数值表示 |
| --- | --- | --- |
| 亚毫米至毫米 | 可辨认的蓝色闪粉、亮片 | 显式粒子 |
| 数十至数百微米 | 密集但仍会形成离散闪点的较大珠光片 | 连续浓度场与统计 glint 的混合 |
| 数微米至数十微米 | 形成乳白、金色云雾和丝绸光泽的细珠光粉 | 多组分连续场 |

若把直径 1 μm 的球形颗粒装满 1 cm³，数量级约为 `1.9×10^12`；即便只有 10% 体积分数也约为 `1.9×10^11`。真实珠光片不是球体，浓度和粒径分布也未知，但这个估算已经足以说明：逐粒模拟微细珠光粉在 PC 和移动端都不现实，也没有视觉必要。

### 视频样本

本次分析使用本地、未纳入仓库的 `Example.mp4`：1080×1920、约 30 FPS、675 帧、22.50 秒。使用等时间抽帧、0.5 秒阶段序列和 HSV 颜色纵向分布图进行了观察。由于视频没有标尺、材料表、受控照明和完整翻转前动作，下述时间只用于建立视觉基准。

观察到的过程是：

| 时间 | 观察 |
| --- | --- |
| 0–1 秒 | 蓝色、金橙色和浅色珠光层在上部形成较清楚的水平分带；界面很快失稳。 |
| 1–4 秒 | 金色团块与浅色云雾形成向下延伸的舌状、指状结构；蓝色亮粉从上层形成大量细长下落轨迹。 |
| 4–8 秒 | 蓝色物质已明显到达底部并快速累积；中部仍存在波纹、羽流和回卷结构。 |
| 8–12 秒 | 大部分蓝色已经形成底层，但仍有一个较集中的蓝色团块滞留在上部并继续破碎下沉。 |
| 12–15 秒 | 最后的集中团块消散，宏观流动显著减弱，分层重新建立。 |
| 15–22.5 秒 | 底部形成深蓝层，其上是金橙层，上部保持浅色珠光云雾；界面是有厚度、略倾斜的过渡带而非理想直线。 |

画面中同时存在以下视觉信号：

- 可逐个辨认、在强光下产生高亮彩色闪点的蓝色亮粉。
- 数量更多、形成连续色带但仍带细碎闪点的金橙色颗粒。
- 不能逐个辨认、表现为乳白或淡金云雾、褶皱和丝状纹理的细珠光粉。
- 颗粒下沉引起的羽流、指状前沿、回流和局部团聚；它们不是单纯的噪声纹理。
- 静止后按颜色重新分层，说明不同组分具有不同的有效沉降速度。

视频最像“翻转后的颗粒悬浮层失稳”，而不是一个自由液面被摇晃。沉降悬浮液在 Hele–Shaw 类薄腔中可以出现 Rayleigh–Taylor 型不稳定；相关实验使用翻转后的甘油—砂悬浮液，并以具有空间变化的密度和黏度的一流体模型解释生长前沿。[Völtz、Pesch 与 Rehberg，2001](https://doi.org/10.1103/PhysRevE.65.011404)

这意味着画面中的“流体感”主要来自两件事的组合：颗粒相对油的沉降，以及颗粒浓度改变混合物密度后对油产生的反馈。只计算油拖曳粒子而完全忽略颗粒对油的影响，会失去视频中最重要的羽流和指状结构。

## 物理问题的拆分

### 密闭油层不是浅水

浅水方程描述的是水平尺度远大于水深、且自由表面高度会变化的流体。流沙麻将的腔体接近充满，主要边界是两块平行亚克力板和封闭侧壁，并没有承担主要运动的自由液面。因此把油建模为高度场会引入错误的表面波机制，也无法自然表达填满腔体后的压力约束。

更接近的几何模型是 Hele–Shaw cell：三维不可压缩流体夹在小间距平板之间，再沿厚度方向平均。经典 Darcy 近似会丢掉平面惯性和大部分旋涡；包含平面黏性、惯性和薄腔阻力的 Navier–Stokes–Darcy/Brinkman 层级更适合本项目。相关推导给出了从完整深度平均模型到 Brinkman 和 Darcy 的模型层次，并指出保留惯性的模型与实验更一致。[Logvinov 等，2016](https://doi.org/10.1016/j.actaastro.2016.02.022)

推荐的二维流体骨架是：

```text
∇·u = 0

∂u/∂t + (u·∇)u =
    -∇p/ρ₀ + ν∇²u - κu
    + f_buoyancy + f_frame + f_particles

κ ≈ 12ν/h²
```

其中 `u` 是腔体平面内的深度平均速度，`h` 是腔体厚度，`κu` 是前后两块板造成的线性阻尼。`κ` 在项目中应作为由真实间隙和观感共同标定的参数，而不是假装精确已知。

### 容器固定坐标与惯性项

模拟域固定在容器局部坐标中仍然是正确方向。这样边界不会移动，移动端和 PC 端也能共享同一输入接口。容器运动必须先形成连续运动学状态：

```text
ContainerKinematics = { position, orientation,
                        linearVelocity, angularVelocity,
                        linearAcceleration, angularAcceleration }
```

在容器坐标中，一个位置为 `r`、相对速度为 `v` 的物质点受到的有效加速度可写成：

```text
g_eff = Rᵀ(g_world - a_origin)
        - α × r
        - ω × (ω × r)
        - 2ω × v
```

各项分别对应重力与原点平动、Euler 项、离心项和 Coriolis 项。符号和左右手约定必须在代码中统一测试。

需要注意：对于完全充满、密度均匀的不可压缩液体，均匀的重力或平动加速度大部分可以被压力梯度平衡，本身不会凭空产生持续旋涡。真实的内部运动主要来自旋转与壁面、颗粒相对运动、浓度导致的密度差，以及可能存在但尚未确认的气泡。若希望“猛烈平移”产生丰富涡流，就必须至少有颗粒对流体的双向反馈，而不能只向均匀油场加入一个常量力。

### 单粒沉降与分层

对低粒子 Reynolds 数的孤立球体，Stokes 沉降速度给出基础量级：

```text
v_t = (ρ_p - ρ_f) |g_eff| d² / (18μ)
```

它说明：

- 运动方向由密度差 `ρ_p - ρ_f` 决定，不由颗粒大小单独决定。
- 在同材质、同形状的近似下，直径增大通常使沉降更快，速度与 `d²` 成正比。
- “大颗粒上浮、小颗粒下沉”不能只用尺寸解释；必须存在密度、材质、形状、附着、团聚或回流携带方面的差异。
- 珠光粉和闪粉是薄片而不是球，Stokes 公式只能提供初值，最终需要形状修正和视频标定。

同颜色也不需要只有一个粒径。每种颜色可以包含两到三个等效尺寸档，以产生宽沉降速度分布和有厚度的分层界面。

### 高浓度下的受阻沉降与堆积

当颗粒体积分数达到几个百分点以上，颗粒就不再独立沉降。相邻颗粒造成的流动干扰和油的向上回流会降低平均沉降速度；常用经验形式是：

```text
v_hindered = v_t (1 - φ/φ_max)^n
```

`φ` 是总固相体积分数，`φ_max` 是允许的最大堆积体积分数。受阻沉降研究显示，这种影响在体积分数只有几个百分点时就可能明显；多分散悬浮液会发生差异沉降和组分分离。[Baas 等，2022](https://doi.org/10.1002/dep2.176) [Bürger 等，2001](https://www.math.umd.edu/~tadmor/centpack/publications/files/BFHK_Polydisperse-Suspensions.JEM01-centpack.pdf)

项目中“沉到底部”不能等同于把粒子速度设为零。需要同时描述：

- 浓度接近 `φ_max` 后沉降通量逐渐归零。
- 新到颗粒推动或覆盖已有沉积层。
- 不同组分按有效沉降速度形成有厚度的色带。
- 容器再次翻转或剪切足够强时，沉积层可以重新悬浮。

第一版可以使用每个颜色/尺寸档的沉积质量场；只有宏观亮片才需要粒子接触约束。若直接对十万显式粒子做致密接触，则需要均匀网格邻域搜索，不能使用 `O(N²)` 配对。

## 推荐的混合数值模型

### 珠光粉：多组分 Eulerian 浓度场

对每个颜色与等效粒径档维护一个浓度 `c_k(x,t)`：

```text
∂c_k/∂t + ∇·[c_k (u + w_k)]
    = ∇·(D_k ∇c_k) + S_k

w_k = signedSettlingSpeed_k(φ, |g_eff|) · ĝ_eff
φ = Σ c_k
```

这里：

- `u` 携带全部珠光粉，形成整体回卷和羽流。
- `w_k` 是该组分相对于油的沉降或上浮速度，产生颜色分层。
- `D_k` 主要表示未解析的小尺度混合和数值扩散，不应被解释为很强的布朗运动。
- `S_k` 处理沉积、再悬浮或组分转换；没有这些需求时为零。

不需要把连续粒径分布离散成数十档。两到四个具有清楚视觉职责的组分通常已经足够；是否增加组分由视频误差决定。

### 珠光粉对油的反馈

浓度场不能永远只是被动染料。以 Boussinesq 近似计算混合密度：

```text
ρ_mix ≈ ρ_f + Σ (ρ_p,k - ρ_f) c_k
```

然后只把相对于参考密度的部分作为浮力反馈加入流体动量方程。这能让上重下轻的颗粒悬浮层自行形成指状下降和补偿回流，是参考视频的核心候选机制。

后续如果密集区流动仍然过快，再让有效黏度随 `φ` 增大。不要一开始同时加入密度反馈、浓度黏度、复杂非牛顿流变和颗粒压力，否则无法判断哪一项改善了画面。

### 大闪粉：Lagrangian 代表粒子

可辨认的亮片采用显式粒子。其基础动力学是浮重力、相对流速拖曳、容器惯性项、壁面与颗粒接触：

```text
dv_p/dt = g_eff,p + (u(x_p) - v_p)/τ_p
          + a_contact + a_two_way_correction
```

`τ_p` 控制粒子追随油速的快慢。对薄片，它还依赖姿态和迎风面积。项目可以先将每个粒子视为具有等效直径和随机形状因子的代表粒子，再逐步增加片状姿态。

PBF 适合通过位置约束近似不可压缩流体；它不是描述数十亿珠光粉的必要条件，也不会自动产生多组分沉降和珠光光学。PBF 可以在后期用于大闪粉的接触或统一约束框架，但不应成为整个项目的主流体模型。[Position Based Fluids](https://blog.mmacklin.com/publications/)

图形学中确实存在以 SPH 统一流体和颗粒材料的完整耦合方案，但其目标通常是水渗入颗粒床、泥浆等三维现象，成本和问题结构都重于 Flowama 所需的薄腔视觉模型。[Mixing Fluids and Granular Materials](https://diglib.eg.org/items/a0299950-16cd-421b-91e3-19ce461e133b)

### 厚度方向：最低限度的 2.5D

完全二维会遗漏一个重要事实：容器倾斜时，重力的法向分量会把薄片压向前板或后板，从而改变摩擦、可见性和反光方向。

推荐逐级增加：

- 流体仍保持二维深度平均。
- 大闪粉额外保存归一化深度 `z∈[-1,1]` 和片面法线。
- 珠光浓度可拆成自由悬浮量、前板沉积量和后板沉积量，而不建立完整三维网格。
- 法向重力决定壁面附着倾向；切向流速和强加速度决定再悬浮。

这已经足以让六自由度旋转产生可见差异，同时保持移动端可行性。

## 数值求解建议

网格流体可以从经典的投影法开始：外力、速度平流、黏性、压力投影。Stable Fluids 的半拉格朗日平流稳定且易于学习，GPU Gems 给出了完整的二维 GPU 实现路径。[Stam，1999](https://graphics.stanford.edu/courses/cs448-01-spring/papers/stam.pdf) [GPU Gems，第 38 章](https://developer.nvidia.com/gpugems/gpugems/part-vi-beyond-triangles/chapter-38-fast-fluid-dynamics-simulation-gpu)

第一阶半拉格朗日法会快速抹掉细长羽流。参考视频依赖有厚度但清楚的丝状前沿，因此在基础求解正确后，应升级到带限制器的 MacCormack 或 BFECC 平流。BFECC 的目的正是减少速度和密度平流中的数值耗散。[FlowFixer](https://faculty.cc.gatech.edu/~jarek/papers/FlowFixer.pdf)

不建议一开始加入 vorticity confinement。它会制造更强旋涡，但也可能掩盖密度耦合、边界或输入运动学的错误。只有确认网格耗散导致应有旋涡消失后，才把它作为有明确上限的视觉补偿。

为了避免高频操作被 30/60 FPS 吞掉：

- SDL 输入事件保留时间戳，生成连续容器目标轨迹。
- 物理使用固定步长，初始目标可以是 120 Hz；猛烈动作触发受上限约束的子步，而不是直接跳变姿态。
- 鼠标和传感器都先经过同一个 `MotionController`，得到 `p,q,v,ω,a,α`。
- 自动化直接回放标准化的 `ContainerKinematics`，只用少量测试验证鼠标到控制意图的映射。
- 不从渲染帧之间的位置差直接估算加速度；这样会把帧率抖动放大成不真实的冲击。

## 珠光与闪粉的渲染模型

### 珠光不是普通自发光噪声

云母基珠光来自有涂层片状微粒的干涉、反射、透射和多次散射；外观强烈依赖片层密度、法线分布、材料厚度以及光照/观察角度。[Guillén 等，2020](https://rgl.epfl.ch/publications/Guillen2020Pearlescent)

项目无需实时求解完整波动光学，但至少要保留以下对应关系：

- 浓度控制吸收、遮蔽、浑浊度和珠光强度。
- 平均片面方向控制各向异性高光和明暗翻转。
- 颜色组分控制干涉色近似，而不是仅作为透明 RGB 染料。
- 光源、视线和片面半程向量共同决定闪烁，不能仅由时间噪声决定。

可以为每个珠光组分保存一个便宜的二维方向或二阶方向矩。其演化先采用“随流体旋转、向局部应变方向缓慢对齐、向随机分布松弛”的美术化模型；这比模拟每片云母的转动便宜得多。

### fBm 的正确位置

预制 fBm 噪声仍然有价值，但应承担未解析空间结构，而不是直接决定每帧谁变亮：

- 用流速场平流或扭曲材料空间噪声，补充网格以下的云雾褶皱。
- 用噪声扰动片面方向分布、浓度阈值和局部散射。
- 固定随机种子并保持噪声附着在物质上，避免纹理在原地“烧开”。

若每帧用独立噪声随机提高 HDR 亮度，结果会像视频压缩噪点，而不是随视角和灯光出现的稳定闪点。

### 两级 glint

建议区分：

- 大闪粉 glint：由显式粒子 ID、姿态、光照和视角计算，可产生清楚且可追踪的闪点。
- 亚像素珠光 glint：在每个像素足迹内统计可能朝向光源的微片数量，使用稳定哈希或预滤波随机微表面模型。

实时 glint 研究表明，离散微表面会产生高频、难以抗锯齿的闪烁，预滤波随机微表面可以在实时预算内保持统计正确性和稳定性。[Wang、Deng 与 Holzschuch，2020](https://diglib.eg.org/items/8e3ce697-2376-48b1-8eab-40801ff53134) 多尺度程序材质也提供了稳定渲染亚像素 glint 和各向异性微结构的路线。[Zirr 与 Kaplanyan，2016](https://research.nvidia.com/publication/2016-02_real-time-rendering-procedural-multiscale-materials)

HDR 和 bloom 应位于上述光学响应之后，只放大真正满足反射条件的高亮。它们是相机/显示效果，不是闪粉运动模型。

## 方案比较

| 方案 | 优点 | 主要问题 | 结论 |
| --- | --- | --- | --- |
| 全部使用 PBF/SPH 粒子 | 表示统一，直观，适合学习邻域搜索 | 微珠光数量完全不可承受；高浓度多尺度接触和光学仍未解决 | 不作为主方案 |
| 流体用浅水方程，固体用粒子 | 二维、便宜 | 假设自由液面，和充满的密闭薄腔不符 | 放弃 |
| 经典 Darcy/Hele–Shaw | 极便宜，适合低速薄腔 | 惯性和涡量过弱，猛烈操作时容易显得“停在原地” | 可作对照或低端降级，不作 PC 主模型 |
| 二维 Navier–Stokes | GPU 资料丰富，可产生涡流 | 没有薄腔摩擦；纯被动染料不会自动形成沉降分层 | 作为求解骨架 |
| Navier–Stokes–Darcy + 多浓度场 + 粒子 | 对应薄腔、分层、羽流和离散闪粉；可逐步增加耦合 | 参数较多，需要视频标定；堆积和 2.5D 是难点 | 推荐 |
| 完整三维多相 CFD | 物理上最完整 | 开发、调参、显存和移动端成本远超项目目标 | 不采用 |

## 性能与开发可行性

在桌面 RTX 2080 级 GPU 上，几十万二维网格单元、少量标量场和约十万显式粒子属于合理目标；是否稳定达到 60 FPS 必须用实际 compute shader 和压力迭代次数测量，不能仅凭数量保证。

主要成本来自：

- 压力 Poisson 迭代和高阶平流的多次纹理读写。
- 多组珠光浓度、方向和沉积场的带宽。
- 十万粒子的邻域构建、接触和渲染过绘制。
- 多层透明、HDR glint 与后处理。

推荐先以 256×384 或相近网格验证模型，再评估 512×768；不要在物理机制未确认时追求分辨率。珠光场可以使用半精度存储，但压力和累积量是否可用半精度应由误差测试决定。

移动端迁移仍然可行，因为最昂贵的微珠光已经被连续场代替。移动版可以降低网格、珠光组分、压力迭代和显式粒子数量，同时保留相同的运动学输入及参数语义。完整三维或全部粒子方案则很难保留这条迁移路径。

真正的开发难点按风险排序是：

1. 在未知配方下标定沉降、受阻沉降和浓度反馈，使时间尺度接近实物。
2. 让致密沉积层稳定、可重新翻转，而不出现浓度穿透或数值爆炸。
3. 在二维流体上补足前后板附着与六自由度旋转的视觉差异。
4. 让珠光和 glint 既闪亮又时间稳定，不变成噪点或过曝。
5. 在猛烈操作时保持输入连续、求解稳定且仍有可见的内部相对运动。

这些难点都可以拆成独立可观察的实验，因此项目风险可控。最大的不可行方向是试图一次完成全三维、逐微粒、严格物理的统一模拟。

## 建议的开发顺序

每一步只保留当前被支持的实现；被否定的模型记录结论后从工作区删除。

1. **参考场景与测量**：建立矩形薄腔、固定步长、标准翻转轨迹和离屏输出；记录颜色质心、沉降前沿、静止时间和质量守恒。
2. **薄腔流体骨架**：实现二维不可压缩速度场、压力投影、黏性和薄腔阻尼，用染料确认边界和高频输入不会失效。
3. **多组分沉降**：加入两种连续浓度场、不同有符号沉降速度和最大体积分数，先得到稳定分层。
4. **主动浓度耦合**：让浓度差产生浮力反馈，复现翻转后的指状前沿；随后视耗散情况升级平流。
5. **沉积与再悬浮**：形成有厚度的压实层，并在翻转后重新释放。
6. **大闪粉粒子**：加入流体拖曳、壁面和有限接触；再逐渐提高到目标数量。
7. **珠光方向与光学**：先做连续珠光，再做稳定亚像素 glint，最后增加显式亮片 glint、亚克力和 HDR。
8. **六自由度与猛烈输入**：在标准翻转已经可信后，再接入完整容器运动学、旋转惯性和 2.5D 前后板状态。
9. **移动端预算验证**：以相同场景逐项降低分辨率和组分，确定视觉收益与带宽成本。

PBF、复杂两向粒子接触、非牛顿流变、全三维网格和高级 glint 论文实现都不属于最早的验证路径；只有当前模型的误差明确指向它们时才引入。

## 验证与标定

### 标准场景

最重要的自动化场景不是随机鼠标，而是一条确定的容器运动学轨迹：静置分层、在短时间内旋转 180°、保持、再次回正。所有输入使用固定时间、固定随机种子和固定物理步长。

建议输出以下数值：

- 每个连续组分与显式粒子的总质量误差。
- 每个颜色组分的纵向质心和 10%/50%/90% 分位高度。
- 首次到达底边时间、主沉降前沿位置和静止时间。
- 速度场最大值、散度范数和压力残差。
- 固相超过 `φ_max` 的单元数量。
- 每帧 simulation、particle、render 的 GPU 时间。

图像指标只用来发现明显回归，最终仍需要人工比较：

- 约 1 秒内界面开始失稳。
- 约 1–8 秒存在从上层向下发展的舌状、指状和羽流结构。
- 蓝色组分较早到达底部，同时保留少量延迟下沉团块。
- 约 12–15 秒宏观结构转为稳定分层，之后仍有细微珠光运动。
- 最终形成深蓝、金橙、浅珠光的有厚度过渡，而不是三个完全锐利的矩形色块。
- 闪点附着在运动物质上，移动和静止时都没有随机“烧开”。

这些时间来自当前视频观察，不是通用材料常数。将来更换配方或美术主题时，应保存场景语义而允许参数变化。

### 仍需补充的实物数据

仅凭视频不能确定：

- 腔体内部长宽、实际间隙和填充率。
- 是否存在不可见的小气泡或两种基液。
- 各颜色材料的粒径分布、密度、片厚和质量比例。
- 流沙油密度、运动黏度及其温度依赖。
- 颗粒是否明显吸附在前后板，是否发生不可逆团聚。
- 视频是否经过变速、HDR、美颜或强锐化。

若能获得一个实体样本，最有价值的不是拆解配方，而是在固定相机和灯光下拍摄：180° 翻转、缓慢倾斜、短促平移、绕法线旋转和完全静置。测出容器尺度和几条颜色前沿的位移—时间曲线，就足以校准第一版模型。

## 当前决策边界

- **采用**：容器固定坐标、固定物理步长、薄腔深度平均流体、多组分连续珠光场、显式大闪粉、分层渲染。
- **首要验证**：浓度沉降加主动密度反馈能否产生参考视频中的指状结构。
- **暂缓**：全三维、多亿粒子、统一 PBF/SPH、完整波动光学、复杂非牛顿流变。
- **允许的美术近似**：受控的亚网格噪声、统计 glint、有限 vorticity 补偿和经验沉积率；必须标明其作用，不冒充材料测量结果。
- **失败判据**：若二维主动浓度模型在合理参数下无法同时得到沉降时间、指状前沿和最终分层，再评估更强的两向耦合或局部三维，而不是提前保留多套备用引擎。
