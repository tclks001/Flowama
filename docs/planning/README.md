# Flowama 工作安排

本目录保存项目的粗略开发阶段与近期计划，供项目所有者安排学习和复盘。它不描述当前已经实现的系统，也不构成不可变更的承诺。

- 当前实现和可重复使用的说明位于上级 [`../README.md`](../README.md) 及其链接页面。
- 实际发生的工作、决策和验证结果位于 [`../../progress/README.md`](../../progress/README.md)。
- 当样本测量、实验结果或可投入时间改变假设时，直接更新或替换本目录的计划；不要把计划项标记为“完成”。完成事实只写入 `progress/`。
