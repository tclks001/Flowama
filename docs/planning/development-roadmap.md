# 开发阶段与近期工作安排

> 这是用于安排学习与开发节奏的预测，不是进度记录，也不代表技术方案或工期已经敲定。后续应依据实体样本测量、实验结论和实际可投入时间调整；实际完成事项仅记录到 `progress/`。

## 规划依据与节奏

目标是完成一个可交互的桌面流麻摆件：在薄腔、黏性流体中呈现多类悬浮物翻转后的漂移、下沉、分层和闪烁。项目同时服务于 C++、OpenGL 与 GPU 模拟学习，因此优先保证核心玩法、视觉结果和数据流可被项目所有者解释，而不以最快堆叠功能为目标。

以下时间是以每周稳定投入约 8--12 小时作出的粗略估计。达到第一个可信的交互原型约需 6--10 周；完成可自行调参、接近实物观感的桌面版本约需 4--6 个月。它们是工作量范围，不应当作为截止日期。

## 总体阶段

| 阶段 | 预期产出 | 预计投入 |
| --- | --- | --- |
| 参考与实验基线 | 固定步长、可回放的容器运动、自动截图/录像、参数与结果记录方式 | 约 2 周 |
| 容器与基础交互 | 可通过鼠标控制的容器；静态多层流麻摆件画面 | 约 1--2 周 |
| 薄腔流体学习切片 | GPU 网格速度场、边界、压力投影与标量平流的独立实验 | 约 3--5 周 |
| 多层流麻核心 | 多组分浓度场、沉降、密度反馈和翻转后的指状下沉/重新分层 | 约 4--6 周 |
| 亮粉与堆积 | 宏观亮粉的拖曳、边界、沉积与必要的再悬浮 | 约 3--5 周 |
| 材质与交互完成度 | 珠光、稳定闪烁、亚克力外观、六自由度输入与性能调节 | 约 4--8 周 |
| 样本标定与收尾 | 对照实物调参、性能预算、展示录制与当前实现整理 | 约 2--4 周 |

阶段之间可以有少量重叠，但不要在前一阶段的核心验证尚未成立时并行扩张下一阶段。特别是，不在未建立浓度场与流体基线前投入十万级亮粉、完整材质或移动端优化。

## 核心实现顺序

```text
确定性实验台
  -> 容器交互与静态摆件
  -> 二维薄腔流体
  -> 多组分浓度与密度反馈
  -> 宏观亮粉
  -> 珠光、闪烁与亚克力
  -> 实物标定与性能收敛
```

细珠光层先作为连续浓度场处理；肉眼可辨识的较大亮粉才作为独立粒子。这样可将多层流麻的主运动与高数量粒子的碰撞、渲染问题分开学习和验证。

## 实体样本到货前的两周

样本到货前以建设实验基础和完成独立学习切片为主，不以复刻某个具体样本为验收目标。

### 第一周：确定性实验台与容器表达

- 明确容器局部坐标、世界坐标、重力和屏幕坐标的约定；将鼠标操作转换为高层容器控制意图，而不是让模拟直接读取鼠标位移。
- 建立固定模拟步长与时间戳输入；准备一个标准场景：静止、翻转 180 度、保持、复位。
- 增加可重复的自动运行与截图输出，截图命名包含场景和模拟时刻；仅记录少量必要指标，例如模拟时刻与容器姿态。
- 渲染静态蓝、金、浅色三层以及容器轮廓，先验证窗口、相机与容器交互的可用性。

本周的学习重点是理解“输入 -> 容器运动学 -> 模拟输入 -> 截图验证”的数据流；不要求开始真实流体求解。

### 第二周：GPU 流体最小学习切片与视觉预研

- 在小尺寸二维纹理网格上实现一个独立的标量场平流实验，再加入速度场、边界和压力投影；先保证能够解释每张纹理的职责与每个计算阶段的输入输出。
- 用人为指定的下沉或旋涡速度场驱动多种颜色的浓度场，观察颜色分层、扩散和界面形状；此实验用于分离视觉问题与流体求解问题。
- 初步试验稳定的珠光/亮粉视觉：随机性固定在粒子标识或材质空间，避免每帧重新随机导致闪烁“沸腾”。
- 为样本到货准备测量表和固定拍摄动作：内腔长宽厚、各层比例与视觉颗粒尺度；翻转、慢倾斜、平移、法线轴旋转及静止过程的视频。

本周的成功判据不是“像实物”，而是能够稳定重放一个输入序列，得到相同的输出，并清楚区分平流、扩散、投影和渲染各自造成的画面变化。

## 每个阶段的理解边界

项目所有者应能解释每项核心切片的输入、持久状态、一步更新后的输出，以及其物理或视觉近似的理由。CMake、PowerShell、构建缓存、图像编码和其他辅助实现不要求逐行掌握；它们应保持小而有说明，并在需要修改时再针对性理解。

## 实体样本到货后的调整点

样本到货后先补充测量与固定机位视频，再重新审视本计划的阶段长度和模型优先级。尤其要确认内腔厚度、填充与气泡结构、各类材料的相对体积和沉降时间；这些事实可能改变多组分参数、二维/2.5D 的需求以及渲染重点。
