# 开发与学习记录

本目录按日期保存 Flowama 的开发、实验、阅读与复盘记录，使用相对路径，随仓库一起迁移。

## 日记录

每日记录放在 `YYYY/MM/DD/README.md`。例如：`2026/08/20/README.md`。

日记录应简要写明：完成的事项、关键决定或发现、验证证据、未解决问题，以及下一步。

## 周与月概述

- 下周第一次创建日记录时，在当月目录新增 `week-YYYY-Www.md`，概述刚结束的一周。
- 下月第一次创建日记录时，在当年目录新增 `month-YYYY-MM.md`，概述刚结束的一个月。

概述只总结已完成的事实、风险与下一阶段重点；不要替代对应的日记录。
