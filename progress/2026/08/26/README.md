- 对比了两种重采样思路。若一次输入是绕单轴的旋转，均分鼠标位移与对旋转四元数作 SLERP 完全等价；但当前映射把水平、垂直拖拽按顺序组合为两个不同轴旋转，`(V^(1/n) H^(1/n))^n` 一般不等于 `V H`。为保持已验收的拖拽终点与组合顺序，后续不改为绝对鼠标位置或 Arcball 映射；输入层应保留带时间戳的每事件世界旋转增量 Δq，并使用 `slerp(I, Δq, fraction)` 按固定步时间重叠切分。
- 确定下一输入切片仅做单线程的“SDL 事件时间线 → 120 Hz Δq 切分 → 逐 tick 容器姿态”。渲染、容器和粒子仍共用主线程；线程化、Windows Raw Input、回滚和接触响应不属于该切片。录制与自动化继续以重采样后的固定步 `ContainerPose` 为边界，不记录鼠标位置或未重采样事件。

- 增加 `input_timeline_verification`：构造两段不同轴、跨多个固定步的 Δq，确认分段消费后的终点旋转等于原始事件顺序的组合旋转，并确认输入结束后的空闲区间返回单位旋转。该检查保护“重采样不改变已验收拖拽终点，也不产生输入尾巴”的契约。
- 审阅后为时间线加入固定 4 tick（约 33 ms）的输入缓冲：物理游标稳定落后真实时间，为正常 60 Hz 输入和短时事件抖动提供完整到达的余量。它是容器、粒子和渲染共同采用的显式时间线延后，不是只对惯性力保留历史的导数平均；若单线程过载，模拟时间仍保留并继续落后，而不会丢弃或压缩输入。
