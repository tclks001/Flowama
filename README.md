# Flowama

Flowama 是一个个人图形学学习项目，目标是复刻周边圈透明亚克力“流麻”摆件的交互观感：亮粉在薄容器的黏性液体中随容器倾斜、翻转和晃动而漂移、下沉、堆积，并呈现闪烁与层次感。

项目首先面向桌面端，作为可交互的桌面摆件/小游戏；长期希望能迁移到移动端，使用设备姿态与运动输入把这一体验带到动态壁纸或类似载体中。

## 预期结果

- 用户可通过鼠标或其他输入操控容器的姿态与运动，观察亮粉的连续响应。
- 亮粉并非真空落体，而是受到黏性液体、容器边界、相互作用与惯性效应共同影响。
- 画面应具有透明容器、亮粉层次、缓慢漂移和可控闪烁等流麻特征。
- 项目会从小规模、可验证的原型逐步扩展；十万级亮粉是性能研究目标，而非首个版本的前置条件。

## 学习目标

本项目是作者系统学习实时图形学与 GPU 编程的载体。将循序理解并实践：

1. 可重复的原生 C++ 图形程序开发与调试流程；
2. 着色器、GPU 数据布局、渲染与计算通路；
3. 薄腔黏性液体与亮粉相互作用的实时近似；
4. 非惯性参考系下的交互模拟、固定步长和数值稳定性；
5. 截图、录像、场景回放与性能数据驱动的视觉迭代。

技术栈将保持轻量、原生且面向 GPU 学习；具体选择及其演进以源码、构建配置和开发记录为准。

## 开发方式

每个阶段都应先形成一个可独立运行、可观察、可回放的切片，再进入下一阶段。AI 用于协助编写重复性工程代码、自动化验证和整理资料；核心物理假设、架构边界与最终判断由作者掌握。
